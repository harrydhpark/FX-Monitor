LGE Europe TV Sales Strategy Team PART I. WORKFLOW

F(x) Tracker 환율 모니터링 및 자동 분석 파이프라인 (6-Step Pipeline)

"실시간 환율 수집 및 매크로 코멘터리 연계 프로세스를 지능형 파이프라인으로 일원화하고, Q&A 정합성 필터를 내재화해 무결성을 극대화합니다."

Step 01

실시간 데이터 수집

Yahoo Finance API(yfinance)를 연동하여 EUR, GBP 등 8개 통화의 실시간/과거 환율을 수집

Step 02

캐싱 및 정합성 보장

로컬 메모리 캐시로 API 지연율을 낮추고, 장애 시 real_rates.json 백업 엔진을 구동해 정합성 확보

Step 02.5

Q&A 정합성 검증

AI 자연어 Q&A(/api/query) 파싱 시 정규식 기반 통화 매칭 및 기간 유효성 정밀 검증 장치 도입

Step 03

동적 추이 시각화

Chart.js 라이브러리를 통해 과거 5개월 추세 및 향후 분기별 전망 라인을 실시간으로 시각화

Step 04

코멘터리 전망 편집

Bloomberg Consensus 등 외부 매크로 지표 분석 데이터 입력 및 commentaries.json 즉시 동기화

Step 05

간편 패키징 및 배포

static 폴더 전체의 독립 파일 패키징(Zip) 구성을 설계해 서버 없는 외부 환경에서도 로컬 작동을 완벽 보장

실무적 가치: Q&A 정합성 검증(Step 2.5) 필터를 파이프라인 중간에 내장하여, 오차 없는 실시간 통계 산출을 지원하고 현업 부서의 수치 대조 및 수작업 검증 시간을 80% 이상 절감하였습니다.
Source: LGE Europe TV Sales Strategy Team - FX Monitor project 1 / 2
LGE Europe TV Sales Strategy Team PART II. AGENT STRUCTURE

지능형 멀티 에이전트 협업 아키텍처 (Intelligent Team)

"역할 분담된 AI 에이전트들이 도구 제어 및 상호 검증 루프를 형성하여 F(x) Tracker의 데이터 가공과 대시보드 무결성을 병렬적으로 구현합니다."

🧭
Orchestrator

메인 에이전트

  • F(x) Tracker 전체 기능 명세 및 개발 일정 기획
  • 세부 API 규격 정의 및 서브 에이전트 역할 배치
  • 코멘터리 저장 기능 및 프론트 연동 최종 검수
  • 사용자 요구사항 대응 및 마일스톤 완료 판단
⚙️
Data & Scripter

데이터 에이전트

  • yfinance API 연동 모듈 및 예외 처리 코드 작성
  • 메모리 캐시 관리 로직 및 만료 주기(60분) 구현
  • real_rates.json 백업 환율 데이터 롤오버 엔진 설계
  • 통화별(KRW, HUF 등) 환율 포맷 자릿수 통제
✍️
UI & Content Writer

디자인 에이전트

  • LGE 브랜드 아이덴티티를 반영한 반응형 UI/CSS 구현
  • Chart.js 라이브러리 연동 및 예측선 점선 처리 시각화
  • AI 자연어 Q&A 입력 창 및 답변 렌더링 카드 연계
  • static 폴더 압축(Zip) 클라이언트 공유 기능 설계
🔍
QA & Validator

검증 에이전트

  • /api/query 자연어 질문 파싱 정규식 예외 처리 검증
  • 환율 데이터 API 에러 시 mock 데이터 대체 로직 테스트
  • 통화별 고유 환율 포맷 출력 및 소수점 자리 유효성 감사
  • 정적 index.html의 브라우저 로컬 단독 작동 무결성 검사
협업 아키텍처 특징: 각 에이전트가 단독으로 작업을 끝내는 것이 아니라, '개발 방향 설정(Orchestrator) -> 데이터 구현(Scripter) -> 시각화 구현(UI Writer) -> 상호 검증(QA Validator)'의 내부 품질 순환 루프를 통해 대시보드의 무결성을 보장합니다.
